# Print Cost Calculator v0.3 — Design Spec

- **Date:** 2026-10-19
- **Status:** Draft for review
- **Builds on:** v0.2.0 (`docs/superpowers/specs/2026-10-17-pcc-v0.2-design.md`) — everything there still applies unless changed here.

## 1. Goal

Stop making users re-import the same sliced `.3mf` every session by turning
jobs into saved **projects** with a project list as the home screen; add a
PDF **invoice generator** branded with the user's company name and logo; and
ship a proper **Windows installer** (Inno Setup) that installs into Program
Files.

### Success criteria

1. Closing and reopening the app shows every previously imported/created
   project in a list; opening one shows its plates exactly as saved.
2. Leaving a project with unsaved changes (Back, close app, new project)
   always offers Save / Don't save / Cancel; nothing is lost silently.
3. An invoice PDF can be produced in ≤ 3 clicks from an open project; its
   lines sum exactly to the project's rounded price and it reveals no cost,
   margin or hidden-fee information.
4. Company name and logo are set once in Preferences and reused on every
   invoice.
5. `PrintCostCalculator-<ver>-setup.exe` installs into
   `C:\Program Files\Print Cost Calculator\`, creates Start-menu (and
   optional desktop) shortcuts, upgrades in place, and uninstalls without
   touching user data — proven by an automated silent install/uninstall in
   the release workflow.

### Out of scope (v0.3)

Tax/VAT lines, due dates, payment terms, custom invoice line items, `.3mf`
file association ("Open with"), in-app trash/restore, cloud sync beyond what
OneDrive does to Documents, code signing, CLI/API invoice endpoints (the core
line logic is reusable later), editing issued invoices.

## 2. Decisions taken during brainstorming

| Topic | Decision |
|---|---|
| User data location | Projects + invoices in **Documents\Print Cost Calculator\\**; settings/catalog/logo stay in `%APPDATA%\PrintCostCalculator\` |
| Company info | **Company name** text box + **logo upload** (any Qt-readable image format; scaled down to fit 150×150 keeping aspect, never upscaled; transparency → white; saved as JPEG) |
| Invoice lines | **Clean lines that sum exactly**: one line per plate + Packaging line; rounding delta spread into plate lines; leftover centavos to Packaging; "Rounding" line only as last resort |
| Invoice format | PDF via Qt (`QTextDocument` + `QPdfWriter`), A4 — no new dependency |
| Project prices | Live (recomputed with current rates); the issued PDF is the frozen record |
| Installer | Inno Setup 6, built + smoke-tested in the GitHub release workflow |
| Version | 0.3.0 |

## 4. Data locations (`pcc/core/paths.py`)

- `data_root()`: `PCC_DATA_DIR` env var if set; else
  `documents_dir() / "Print Cost Calculator"`.
- `documents_dir()`:
  - Windows: `SHGetKnownFolderPath(FOLDERID_Documents)` via `ctypes`
    (handles OneDrive-redirected Documents); fallback `~/Documents`.
  - Linux: `XDG_DOCUMENTS_DIR` from `~/.config/user-dirs.dirs` (with `$HOME`
    expansion); fallback `~/Documents`.
  - macOS: `~/Documents`.
- `projects_dir() = data_root()/"Projects"`, `invoices_dir() = data_root()/"Invoices"`; created on first use.
- Settings, catalog and `logo.jpg` remain in `config_dir()` (v0.2 §7).

## 5. Projects (`pcc/core/projects.py`)

### 5.1 Model

```text
InvoiceRecord  number: str, date: str (ISO yyyy-mm-dd), bill_to: str,
               total: float, currency_symbol: str, file: str (absolute path)
Project        schema_version=1, id (new_id("proj")), name: str,
               created_at, updated_at (ISO-8601 datetimes), job: Job,
               invoices: list[InvoiceRecord]
```

### 5.2 On-disk layout

```
Projects/<YYYY-MM-DD> <safe name> (<id suffix>)/
  project.json          Project without thumbnails (UTF-8, ensure_ascii=False)
  thumbs/<plate_id>.png Plate thumbnails (optional)
```

- Folder name fixed at creation (safe name = name with `<>:"/\|?*` and
  control chars removed, trimmed to 60 chars, fallback "Project"); renaming a
  project only changes `name` in `project.json`.
- All writes atomic (temp + `os.replace`, reuse `atomic_write_text`).

### 5.3 API

```text
ProjectError(Exception); ProjectConflictError(ProjectError)
ProjectHandle  path: Path, project: Project       (project.job plates have no thumbnails loaded)
list_projects(root=None) -> tuple[list[ProjectHandle], list[str]]   # handles sorted by updated_at desc, warnings for damaged folders
create_project(name, job, root=None) -> ProjectHandle
load_project(path) -> Project                         # thumbnails loaded
save_project(path, project, expected_updated_at: str | None) -> Project
    # raises ProjectConflictError if on-disk updated_at != expected_updated_at
    # (and expected is not None); sets updated_at=now; writes thumbs that changed;
    # removes thumbs of deleted plates
duplicate_project(path, new_name) -> ProjectHandle    # new id, copies thumbs, no invoices
rename_project(path, new_name) -> Project
```

- Damaged `project.json` (bad JSON / invalid values) → skipped by
  `list_projects` with warning `"<folder>: could not be read"`; never crashes.
- Deleting is a GUI action: `QFile.moveToTrash(folder)`; if that returns
  False, ask "Delete permanently?" and `shutil.rmtree` on Yes.

## 6. GUI: navigation and project lifecycle

### 6.1 Pages

`MainWindow` central area becomes a `QStackedWidget`:

- **ProjectsPage** (start page):
  header `📁 Projects`, search box (filters name + customer,
  case-insensitive), `➕ New`, `📂 Import .3mf`; list rows show thumbnail
  (first plate's, else printer icon), name, customer (or "—"), plate count,
  live price (`format_money`), "edited <date>"; double-click/Enter opens;
  row `⋯` menu: Rename, Duplicate, Show in folder, Delete (confirm
  "Delete '<name>'? It will be moved to the Recycle Bin."). Empty state:
  "No projects yet — drop a sliced .3mf here or click ➕ New". Drop of
  `.3mf` files creates one project per file (name = file stem without
  `.gcode`/`.3mf`), import failures in the banner, then opens the first
  created project. Damaged-project warnings shown in the banner.
- **Editor page**: existing job/plates/summary columns plus `ProjectHeader`
  on top: `[⬅ Back] [💾 Save]  <name ✎>  ● Unsaved changes` (dot + text
  only when dirty). Save disabled when clean. The printer combo moves into
  the editor (it is per-project); currency/theme/settings stay global in the
  top bar.

### 6.2 State (`AppState` additions)

```text
signals  project_opened(), project_closed(), dirty_changed(bool), projects_changed()
attrs    project: Project | None, project_path: Path | None, dirty: bool
new_project(name="Untitled project") -> None          # creates on disk immediately, opens it
open_project(path) -> None
save_project(force=False) -> None                     # ProjectConflictError propagates unless force
close_project() -> None                               # no prompt; GUI prompts before calling
create_projects_from_files(paths) -> tuple[list[Path], list[tuple[str, str]]]
rename_current(name) -> None                          # marks dirty
```

- Job mutations (`add/remove/update_plate`, `update_job`, `import_files`,
  catalog repair that changes the job) set `dirty=True`; settings/theme/
  currency changes do not.
- `new_job()` from v0.2 is replaced by `new_project()`.

### 6.3 Save prompt

`QMessageBox` "Save changes to '<name>'?" with Save / Don't Save / Cancel,
shown when `dirty` and the user: clicks Back, closes the window, presses
Ctrl+N, or opens another project. Save → `save_project()` then continue;
Don't save → discard and continue; Cancel → stay. On
`ProjectConflictError`: "This project was changed elsewhere (another window?).
Overwrite it with your version?" Overwrite → `save_project(force=True)`;
Cancel → stay dirty.

Shortcuts: Ctrl+S save (editor), Ctrl+N new project, Ctrl+O import
(list → new projects; editor → add plates), Ctrl+E export (editor),
Ctrl+I invoice (editor), Alt+Left = Back (same prompt as the button).
Esc does nothing in the editor, to avoid accidental exits.

## 7. Invoices

### 7.1 Preferences — 🏢 Company section

- `Company name` line edit → `Settings.company_name` (default "").
- `Logo`: preview (≤150×150), `Upload…` (`QFileDialog` filter built from
  `QImageReader.supportedImageFormats()`), `Remove`.
  `pcc.gui.logo.load_logo_image(path) -> bytes`: read with `QImageReader`
  (auto-transform on), if width or height > 150 scale with
  `Qt.KeepAspectRatio` + smooth transform, composite onto white, encode JPEG
  quality 90. Saved to `config_dir()/logo.jpg` on dialog OK; Remove deletes
  it. Unreadable image → inline error "Couldn't read that image.".
- Read-only row "Projects folder: <path>" with `Open folder` button.

### 7.2 Numbering

`Settings.next_invoice_number: int = 1`. Default number
`f"INV-{n:04d}"`. On successful creation: if the used number matches
`INV-(\d+)` and `int ≥ next_invoice_number`, set
`next_invoice_number = int + 1`. Duplicate check: any existing file in
`invoices_dir()` starting with `"<number> "` or equal to `"<number>.pdf"` →
warning dialog "Invoice <number> already exists. Create anyway?".

### 7.3 Invoice dialog (`🧾 Invoice`, editor summary panel, next to Export)

Enabled only when `state.quote` is not None and the job has ≥ 1 plate.
If `company_name` is empty → open Settings focused on the Company section
first (must be non-empty to proceed). Fields: Invoice no. (default next),
Date (`QDateEdit`, today), Bill to (customer, editable; may be empty).
`🧾 Create PDF` → file `invoices_dir()/"<number> - <safe bill_to or project name>.pdf"`
(overwrite confirm if exists) → render → append `InvoiceRecord` to the
project → save project (conflict handling as §6.3) → toast
"🧾 Saved INV-0001" with **Open** / **Show in folder**.

### 7.4 Line maths (`pcc/core/invoice.py`, Decimal, 2 dp, ROUND_HALF_UP)

```text
InvoiceLine  description: str, qty: int, unit_price: Decimal, amount: Decimal
build_invoice_lines(job, quote) -> list[InvoiceLine]
```

1. Plate lines in job order: `unit = q2(plate_breakdown.price)` (per copy,
   includes margin + hidden fee), `amount = unit × qty`, description =
   plate name.
2. Packaging line (description "Packaging", qty 1) with
   `amount = q2(quote.packaging × (1 + margin_pct/100))` — only if > 0.
3. `delta = q2(quote.price) − Σ amounts` (in centavos; |delta| ≤ step/2 + rounding noise).
4. Spread delta over plate lines proportionally to their amounts: per line
   `per_unit = trunc_toward_zero(delta × amount/Σplate_amounts / qty)` (to the
   centavo), `unit += per_unit`, `amount = unit × qty`; never let a unit
   price go below 0 (clamp, leaving the rest in the remainder).
5. Remainder `r = q2(quote.price) − Σ amounts`: add to the Packaging line if
   present; else to the largest qty-1 plate line; else append
   `InvoiceLine("Rounding", 1, r, r)` when `r ≠ 0`.

Invariants (tested): Σ amount == q2(quote.price); every `amount == unit × qty`;
no negative unit prices; no line exposes cost/margin/fee values.

### 7.5 PDF (`pcc/gui/invoice_pdf.py`)

`render_invoice_pdf(path, *, company_name, logo_jpeg: bytes | None,
number, date, bill_to, lines, total, currency_symbol) -> None` — HTML in
`QTextDocument` printed to `QPdfWriter` (A4, 15 mm margins, 300 dpi).
Layout: logo (≤150 px) + company name top-left; "INVOICE", No., Date
top-right; "Bill to:" block (omitted if empty); table # / Description / Qty
/ Unit price / Amount (money right-aligned via `format_money`); bold TOTAL
row; footer "Thank you for your business!". HTML-escape all user text.
Writes to a temp file then `os.replace`.

## 8. Windows installer (`packaging/installer.iss`)

- `#define AppVersion` from `/DAppVersion=<ver>` (ISCC command line);
  fixed `AppId={{<GUID>}`; `AppName=Print Cost Calculator`;
  `AppPublisher=KINGdeusX`; `DefaultDirName={autopf}\Print Cost Calculator`;
  `PrivilegesRequired=admin`; `ArchitecturesAllowed=x64compatible`,
  `ArchitecturesInstallIn64BitMode=x64compatible`; `SetupIconFile` and
  `UninstallDisplayIcon` = app icon; `OutputBaseFilename=PrintCostCalculator-{#AppVersion}-setup`;
  `OutputDir=..\packaging\out`; `CloseApplications=yes`;
  `Compression=lzma2/max`, `SolidCompression=yes`; `WizardStyle=modern`;
  `LicenseFile=..\LICENSE`.
- `[Files]`: `..\dist\PrintCostCalculator\*` → `{app}`, recursive.
- `[Tasks]`: `desktopicon` (unchecked by default).
- `[Icons]`: Start menu `{autoprograms}\Print Cost Calculator`; desktop via task.
- `[Run]`: optional "Launch Print Cost Calculator" (`postinstall nowait skipifsilent`).
- Uninstall removes `{app}` only; user data untouched (documented).
- `build_windows.ps1 -Installer` compiles with ISCC if found
  (`${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe`), else errors with a
  clear message.
- Release workflow Windows job: build → `choco install innosetup -y` only
  if ISCC missing → compile → smoke test: `setup.exe /VERYSILENT
  /SUPPRESSMSGBOXES /NORESTART /DIR=<temp>`; run `<temp>\PrintCostCalculator.exe`
  with `PCC_SELFTEST=1` (exit 0); run `<temp>\unins000.exe /VERYSILENT`;
  assert `<temp>\PrintCostCalculator.exe` is gone → upload
  `PrintCostCalculator-<ver>-setup.exe` with the zip.

## 9. Error handling

| Situation | Behavior |
|---|---|
| Damaged project folder | Skipped in list + banner warning |
| Save conflict | Overwrite / Cancel dialog |
| Save fails (locked/disk) | Error dialog with reason; project stays dirty |
| Logo unreadable | Inline error; previous logo kept |
| Invoice file locked / exists | Retry/Cancel (locked) or overwrite confirm (exists) |
| Recycle Bin unavailable | Ask to delete permanently |

## 10. Testing

- **paths**: `PCC_DATA_DIR` override; Linux user-dirs parsing (incl.
  `$HOME/...` and quoted values); fallback to `~/Documents`.
- **projects**: create/list/load/save round-trip incl. thumbnails and
  Unicode names; sort order; damaged folder skipped with warning; conflict
  raises; force path; duplicate (new id, thumbs copied, no invoices); rename
  keeps folder; deleted-plate thumbs removed.
- **invoice maths**: reference job sums exactly; rounding up and down;
  step 0; multi-copy plates keep `unit×qty == amount`; remainder to
  packaging / qty-1 line / "Rounding" line; no negative units; property-style
  loop over random jobs asserting invariants.
- **logo**: large PNG with alpha → ≤150×150, white background, JPEG
  magic bytes; small image not upscaled; unreadable file → error.
- **GUI**: starts on ProjectsPage; drop/import creates projects and opens
  first; open/back navigation; dirty indicator; save prompt Save/Don't/Cancel
  on Back, close and Ctrl+N; conflict dialog; delete → trash (patched);
  search filter; invoice dialog → `%PDF` file, record appended, numbering
  advanced; first-invoice company prompt; settings Company section
  persists name + logo.
- **installer**: static checks on `installer.iss` (AppId present,
  `{autopf}`, version define, Files source path = PyInstaller dist dir,
  OutputBaseFilename pattern); release-workflow smoke install/uninstall.
