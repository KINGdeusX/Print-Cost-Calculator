# Print Cost Calculator v0.2 — Design Spec

- **Date:** 2026-10-17
- **Status:** Draft for review
- **Supersedes:** v0.1.1 (`Cronus.py`, single PyQt5 window)

## 1. Goal

Turn the single-window v0.1.1 calculator into a modern, fast-starting,
cross-platform desktop app with multi-plate quoting, sliced `.3mf` import,
saved printer/filament profiles and appendable Excel reports — built on a
UI-independent core that is also exposed through a CLI and an HTTP/JSON API
so future web clients (any language/framework) can use the same pricing.

### Success criteria

1. A user can drop a Bambu Studio / OrcaSlicer sliced `.3mf` and get a
   per-plate and total price with no manual typing beyond confirming
   filament matches.
2. Every setting, profile and preference survives app restarts.
3. The splash appears < 0.5 s and the main window is usable ≈ 1.5 s after
   launch on a typical machine (measured with `--timing`).
4. Exported reports never reveal the hidden per-plate fee or the margin %.
5. Prebuilt binaries for Windows (x64) and Linux (x86_64, glibc ≥ 2.28 —
   i.e. virtually all current distros) are produced by GitHub Actions and
   attached to GitHub Releases.
6. The same quote is reproducible from GUI, CLI (`pcc quote`) and HTTP API
   (`POST /api/v1/quote`).

### Out of scope (v0.2)

Automations/scheduled workflows, currency conversion, PDF quotes,
PrusaSlicer/Cura/G-code parsing, macOS binaries (code runs there from
source, but no prebuilt artifact), user accounts on the API.

## 2. Decisions taken during brainstorming

| Topic | Decision |
|---|---|
| UI stack | **PySide6** (Qt 6, LGPL) + own QSS theme (light/dark tokens) |
| Hidden per-plate fee | Visible in-app as a dim "🔒 Internal fee" line; **never** in exports or public API responses |
| Failure rate | Allowance = (filament + electricity) × failure %; own line "⚠️ Failure allowance" |
| Filament pricing | Saved **filament library**; 3mf filaments auto-matched |
| Labor / packaging | Labor **per plate**; packaging **once per job** |
| Report | `.xlsx` with **Jobs** + **Plates** sheets; append adds rows; legacy v0.1 sheet preserved |
| Export markup | Shows a single **Markup** amount (price − cost), no margin %, no fee |
| API | Framework-agnostic REST/JSON + OpenAPI 3.1 (FastAPI server, optional extra) |
| Distribution | GitHub repo `KINGdeusX/Print-Cost-Calculator`; CI builds Windows zip + Linux AppImage/tarball on tags |

## 3. Architecture

One Python package, `pcc`, with a dependency-light **core** and three thin
front-ends. The core never imports Qt or web frameworks.

```
                ┌─────────────┐
   GUI (Qt) ───►│             │◄─── CLI  (pcc quote / parse / export / serve)
                │  pcc.core   │
  HTTP API ────►│  (pure Py)  │
                └─────────────┘
```

## 4. Data model (`pcc.core.models`)

All dataclasses; money as `float` internally, final price rounded with
`Decimal` ROUND_HALF_UP.

```text
PrinterProfile  id, name, watts: float, model_match: list[str], notes: str
Filament        id, name, type: str ("PLA","PETG",…), price_per_kg: float,
                color: str ("#RRGGBB"), is_default: bool
FilamentUse     filament_id: str, grams: float, slot: int|None,
                source_type: str|None, source_name: str|None,
                source_color: str|None, match: "exact"|"type"|"default"|"manual"
Plate           id, name, hours: float, copies: int = 1,
                filaments: list[FilamentUse], labor: float,
                source_file: str|None, plate_index: int|None,
                thumbnail_png: bytes|None (not persisted)
Job             id ("YYYYMMDD-HHMMSS"), created_at, customer: str,
                printer_id: str, plates: list[Plate], packaging: float
Settings        schema_version=2, currency_code, currency_symbol,
                electricity_rate, default_labor, default_packaging,
                margin_pct, failure_pct, hidden_plate_fee, rounding_step,
                theme ("system"|"light"|"dark"), last_printer_id,
                last_export_path, window_geometry (base64 str)
Catalog         printers: list[PrinterProfile], filaments: list[Filament]
```

## 5. Pricing (`pcc.core.pricing`)

For each plate *p* with copies *q*, printer watts *W*, rate *R*,
failure *f*, margin *m*, hidden fee *h*:

```
filament_p    = Σ (grams / 1000 × filament.price_per_kg)      # per copy
electricity_p = W / 1000 × hours × R                          # per copy
failure_p     = (filament_p + electricity_p) × f
labor_p       = plate.labor
plate_cost_p  = filament_p + electricity_p + failure_p + labor_p
plate_price_p = plate_cost_p × (1 + m) + h                    # per copy

job_cost      = Σ plate_cost_p × q  + packaging
price_raw     = Σ plate_price_p × q + packaging × (1 + m)
price         = round_half_up(price_raw / step) × step        (step 0 → 2 dp)
markup        = price − job_cost
internal_fee  = Σ h × q
```

`Quote` holds per-plate `PlateBreakdown` (all lines per copy and × copies),
job totals per line, `job_cost`, `price`, `markup`, `internal_fee`,
`total_hours`, `total_grams`. Inputs are validated (non-negative, copies ≥ 1,
unknown filament/printer → `PricingError` with a readable message).

## 6. `.3mf` import (`pcc.core.threemf`, `pcc.core.matching`)

Accepts `.3mf` and `.gcode.3mf` (ZIP). Uses only `zipfile` + `xml.etree` + `json`.

- `Metadata/slice_info.config` (XML) — required. For each `<plate>`:
  `metadata key="index"`, `key="prediction"` (seconds → hours),
  `key="weight"`, and each `<filament id type color used_g used_m>`.
  Plates with no filament usage are skipped.
- `Metadata/project_settings.config` (JSON) — optional: `printer_model`,
  `printer_settings_id`, `filament_settings_id[]` (preset names by slot).
- `Metadata/plate_<N>.png` — optional thumbnail.
- Plate name: `plate_name` metadata if present, else `"<file stem> · Plate N"`.

Errors (`ThreeMFError`, message shown to user):
- not a ZIP / corrupt → "Not a valid .3mf file."
- no `slice_info.config` or no sliced plates → "No slice data. In Bambu
  Studio/OrcaSlicer use 'Export plate sliced file' or 'Export all sliced files'."

Matching:
- Printer: first profile whose `model_match` entry is a case-insensitive
  substring of `printer_model` or `printer_settings_id`; else keep current.
- Filament (per slot): exact preset-name match on `Filament.name` → `exact`;
  else same `type` (prefer default, then first) → `type`; else default
  filament → `default`. Non-`exact` matches get a 🟡 badge in the GUI.

## 7. Persistence (`pcc.core.storage`)

- Config dir: `PCC_CONFIG_DIR` env var if set; else Windows `%APPDATA%\PrintCostCalculator`,
  macOS `~/Library/Application Support/PrintCostCalculator`, Linux
  `$XDG_CONFIG_HOME/print-cost-calculator` (default `~/.config/...`).
- Files: `settings.json`, `catalog.json` (printers + filaments).
- Atomic writes (temp file + `os.replace`). Corrupt JSON → renamed to
  `*.bak-<timestamp>`, defaults loaded, GUI shows a banner.
- First run: if a v0.1 `pricing_config.json` exists next to the executable or
  in the CWD, import `filament_cost` (→ default filament price), `packaging`,
  `rate`, `power` (→ "My Printer" profile, selected), `margin`.
- Seed catalog: Bambu presets (A1 mini 80 W, A1 100, A2L 100, P1P 130,
  P1S 130, P2S 140, X1 140, X1 Carbon 140, X1E 160, X2D 170, H2S 210,
  H2D 240, H2D Pro 240, H2C 240 — "indicative averages, measure with a plug
  meter"), plus a generic "Custom FDM 150 W"; filaments PLA, PETG, ABS, ASA,
  TPU, PLA-CF generic entries priced from the default.
- Defaults: currency PHP ₱, rate 12/kWh, labor 0, packaging 20, margin 50 %,
  failure 0 %, hidden fee 0, rounding step 5, theme system.
- GUI saves debounced (500 ms) on every change and on close.

## 8. Interfaces beyond the GUI

### 8.1 CLI (`pcc`, stdlib only)

```
pcc quote  FILE.3mf [--printer ID] [--copies N] [--customer NAME]
           [--json] [--internal] [--export REPORT.xlsx [--append]]
pcc parse  FILE.3mf [--json]
pcc printers | filaments [--json]
pcc serve  [--host 127.0.0.1] [--port 8765]        (needs [api] extra)
pcc-gui    [--timing]                               (needs [gui] extra)
```

`--json` prints the same structures as the API. Exit codes: 0 ok,
2 bad input, 3 file error. This is also the hook for future automations.

### 8.2 HTTP API (`pcc.api`, FastAPI, OpenAPI 3.1 at `/openapi.json`, docs at `/docs`)

Framework-agnostic: plain JSON over HTTP, so React/Vue/Svelte/Flutter/
mobile/PHP/etc. clients can call it or generate SDKs from the OpenAPI file.

| Method | Path | Auth | Purpose |
|---|---|---|---|
| GET | `/api/v1/health` | — | `{status, version}` |
| GET | `/api/v1/printers` | — | public list: id, name |
| GET | `/api/v1/filaments` | — | public list: id, name, type, color (no prices) |
| POST | `/api/v1/parse` | — | multipart `.3mf` → plates (hours, grams, filaments, matches) |
| POST | `/api/v1/quote` | — | JSON job → public quote |
| POST | `/api/v1/quote/3mf` | — | multipart `.3mf` + options → public quote |
| POST | `/api/v1/export/xlsx` | admin | JSON job → `.xlsx` download |
| GET/PUT | `/api/v1/admin/settings` | admin | read/replace server settings |
| GET/PUT | `/api/v1/admin/catalog` | admin | read/replace printers & filaments |

- **Public quote** = per-plate price, copies, hours, grams, total price,
  currency. No cost lines, margin, fee or filament prices.
- **Internal quote** (admin token, `?view=internal`) = full `Quote`.
- Admin auth: `Authorization: Bearer <PCC_ADMIN_TOKEN>`; if the env var is
  unset, admin routes return 403.
- CORS origins from `PCC_CORS_ORIGINS` (comma list; default none).
- Upload limit 50 MB; errors as `{"error": {"code", "message"}}` with 4xx.
- Pricing settings always come from the server's config dir — clients
  cannot override margin/fee/rates.
- Deploy: `pip install print-cost-calculator[api]` + `pcc serve`, or the
  provided `Dockerfile`.

## 9. GUI (`pcc.gui`)

### 9.1 Layout (live recalculation — no "Calculate" button)

```
┌ 🖨️ Print Cost Calculator  [🖨️ Printer ▾] [₱ PHP ▾] [🌙/☀️] [⚙️] ┐
│ 👤 JOB            │ 🧩 PLATES                 │ 💰 SUMMARY          │
│ Customer/project  │ ┌ Plate card ──────────┐  │ per-plate rows      │
│ 📦 Packaging      │ │ thumb · name · ✖     │  │ 🧵 ⚡ ⚠️ 🛠 📦 lines │
│ 📈 Margin %       │ │ ⏱ d h m · copies ×   │  │ 🔒 Internal fee     │
│ ⚠️ Failure %      │ │ 🧵 filament rows 🟡  │  │ 💵 PRICE (large)    │
│                   │ │ 🛠 Labor             │  │ [📤 Export ▾]       │
│                   │ └──────────────────────┘  │                     │
│                   │ [➕ Add plate] [📂 Import] │                     │
│                   │ ⇣ Drop sliced .3mf here   │                     │
└───────────────────┴───────────────────────────┴─────────────────────┘
```

- Numeric inputs are spin boxes (no free-text parse errors); tooltips on
  every field; empty state explains "Drop a sliced .3mf or add a plate".
- Below ~1000 px width the summary moves under the plates.
- Drag & drop anywhere on the window; multiple files; overlay highlight on
  drag-over; failures listed in a dismissible banner, successes imported.
- 🟡 badge on non-exact filament matches; clicking opens the filament picker.
- Dialogs: ⚙️ Settings (rates, defaults, margin, failure, hidden fee,
  rounding, currency, theme), 🖨️ Printers, 🧵 Filaments (add/edit/delete,
  set default). Deleting an in-use profile falls back to default with a notice.
- Keyboard: Ctrl+O import, Ctrl+N new job, Ctrl+E export, Ctrl+, settings.

### 9.2 Theme

Token set (bg, surface, surface-2, border, text, text-muted, accent,
accent-text, success, warning, danger) defined for light and dark; QSS is
generated from tokens. "System" follows `QStyleHints.colorScheme()` and
updates live. Fusion style base, 8 px radii, card surfaces, accent buttons.
SVG icons are recolored to the current text color at load time.

### 9.3 Startup path

1. `pcc.gui.app` imports only `QtCore/QtGui/QtWidgets`, creates the app and
   shows the splash (logo + status text) immediately.
2. Loads settings/catalog, imports `main_window` (and theme), builds UI,
   updating splash status; then shows window and closes splash.
3. `openpyxl` imported only on export; dialogs imported on first open.
4. `--timing` logs ms per stage to stderr.

### 9.4 Export flow

📤 menu: **New report…**, **Append to existing…**, **Append to last
(`name.xlsx`)** (disabled if none). Permission error (file open in Excel) →
dialog "Close the file in Excel, then retry" [Retry][Cancel]. Success →
toast with **Open file** / **Open folder**.

## 10. Excel report (`pcc.core.export_xlsx`)

- **Jobs**: Job ID, Date, Customer, Printer, Currency, Plates, Copies,
  Hours, Grams, Filament, Electricity, Failure allowance, Labor, Packaging,
  Total cost, Markup, Price.
- **Plates**: Job ID, Plate #, Plate, Source file, Copies, Hours/copy,
  Grams/copy, Filaments (e.g. "PLA Basic 42.1 g; PETG HF 3.0 g"),
  Filament, Electricity, Failure allowance, Labor, Plate cost, Plate price
  (both × copies).
- Bold header row, frozen panes, auto column widths, money format
  `"<symbol>"#,##0.00`.
- Append: open existing, add rows to both sheets (create missing sheets).
  A workbook whose first sheet has the v0.1 headers (`date, name,
  duration, …`) keeps that sheet renamed "Legacy v0.1".
- Never written: margin %, hidden fee, filament price per kg.

## 11. Build, release, version control

- Git: work on branch `feature/v0.2`, commit per plan task, push to
  `origin` (`github.com/KINGdeusX/Print-Cost-Calculator`), merge to `main`
  when complete, tag `v0.2.0`.
- `ci.yml`: on push/PR — matrix ubuntu-latest + windows-latest, Python 3.11
  and 3.13; install `.[gui,api,dev]`; `pytest` (Qt offscreen).
- `release.yml`: on tag `v*`:
  - **Windows**: PyInstaller one-dir → `PrintCostCalculator-<ver>-windows-x64.zip`.
  - **Linux**: built inside `quay.io/pypa/manylinux_2_28_x86_64` (glibc 2.28,
    covers Ubuntu 20.04+, Debian 11+, Fedora, RHEL/Alma/Rocky 8+, Arch,
    openSUSE, Mint, Pop!_OS…) → `PrintCostCalculator-<ver>-x86_64.AppImage`
    and `…-linux-x86_64.tar.gz`.
  - **Python**: sdist + wheel attached (for `pip install`).
  - All attached to a GitHub Release created by the workflow.
- PyInstaller: one-dir, `console=False`, icon, excludes QtWebEngine*,
  QtQml*, QtQuick*, Qt3D*, QtMultimedia*, QtPdf*, tkinter; no UPX.
- Local "precompile": `packaging/build_linux.sh` is run on this machine to
  verify the Linux build; Windows binaries come from CI (PyInstaller cannot
  cross-compile).

## 12. Error handling summary

| Situation | Behavior |
|---|---|
| Corrupt settings/catalog | backup `.bak-<ts>`, defaults, banner |
| Bad/unsliced 3mf | per-file reason in banner; others still import |
| Unknown printer/filament id | fall back to default + notice |
| Export file locked | Retry/Cancel dialog |
| API invalid input | 422 / 400 JSON error; never 500 for user input |

## 13. Testing

- **pricing**: hand-computed cases — single plate, failure %, copies, hidden
  fee, packaging once, margin, rounding (half-up, step 0), validation errors.
- **threemf**: synthetic fixture zips (multi-plate, multi-filament, missing
  project settings, unsliced, corrupt); real sample files if supplied.
- **matching**: exact / type / default paths, printer model match.
- **storage**: round-trip, atomic write, corrupt → backup, v0.1 migration,
  `PCC_CONFIG_DIR`.
- **export_xlsx**: new file, append, legacy upgrade, no margin/fee columns.
- **serialize**: public view contains no internal fields.
- **cli**: `quote --json` on a fixture equals `compute_quote` output.
- **api**: httpx TestClient — public endpoints, admin 403/200, upload, CORS.
- **gui smoke** (pytest-qt, offscreen): launch, import fixture, summary
  price matches core, theme toggle, settings persisted across restart.
