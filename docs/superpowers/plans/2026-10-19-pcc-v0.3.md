# Print Cost Calculator v0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add saved projects (project list home screen with Back/Save and unsaved-changes prompts), a branded PDF invoice generator, and an Inno Setup Windows installer to the v0.2 `pcc` app, released as v0.3.0.

**Architecture:** New stdlib-only core modules (`paths`, `projects`, `invoice`) hold storage and invoice maths; the GUI gains a `QStackedWidget` (ProjectsPage ↔ editor), project lifecycle on `AppState`, Qt-based logo processing and PDF rendering, and Company settings; packaging gains `installer.iss` compiled and smoke-tested in the release workflow.

**Tech Stack:** Python ≥ 3.10, PySide6-Essentials (QTextDocument, QPdfWriter, QImageReader), openpyxl, pytest + pytest-qt, PyInstaller, Inno Setup 6, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-19-pcc-v0.3-design.md` (binding). The v0.2 spec/plan (`docs/superpowers/specs/2026-10-17-pcc-v0.2-design.md`) describes the existing code.

## Global Constraints

- `pcc/core/paths.py`, `pcc/core/projects.py`, `pcc/core/invoice.py` import only the stdlib and `pcc.core.*` — no PySide6/fastapi/pydantic/openpyxl (extend `tests/test_scaffold.py::test_core_and_cli_are_framework_free` to import them).
- `__version__ = "0.3.0"`.
- Data root: `PCC_DATA_DIR` env var, else `documents_dir()/"Print Cost Calculator"`; `Projects/` and `Invoices/` beneath it. Settings, catalog and `logo.jpg` stay in `config_dir()`.
- Tests must never touch the real Documents folder: an autouse fixture in `tests/conftest.py` sets `PCC_DATA_DIR` to a per-test tmp dir (Task 1).
- All JSON is UTF-8 with `ensure_ascii=False`; all project/invoice writes are atomic (temp file in the same dir + `os.replace`).
- Invoices and the project list never show cost lines, margin %, hidden fee or filament price/kg.
- Exact user-facing copy (verbatim): `"Save changes to '<name>'?"`; `"This project was changed elsewhere (another window?). Overwrite it with your version?"`; `"Delete '<name>'? It will be moved to the Recycle Bin."`; `"No projects yet — drop a sliced .3mf here or click ➕ New"`; `"Couldn't read that image."`; `"Invoice <number> already exists. Create anyway?"`; `"Thank you for your business!"`; `"● Unsaved changes"`; buttons `"⬅ Back"`, `"💾 Save"`, `"🧾 Invoice"`, `"➕ New"`, `"📂 Import .3mf"`; section `"🏢 Company"`.
- Default project name `"Untitled project"`; invoice number format `f"INV-{n:04d}"`; logo max 150×150, JPEG quality 90, white background.
- Implementers commit only (no push); commit trailer from your own system attribution reminder.
- Tests run offscreen (`QT_QPA_PLATFORM=offscreen`, already set in conftest); full suite: `timeout 180 .venv/bin/pytest -q -p no:cacheprovider`.

## Review Focus

1. **Project whose plates reference a since-deleted printer/filament** → opening repairs to defaults, shows the existing warning, and marks the project dirty (so the repair can be saved). Test in Task 5.
2. **Project names that are illegal or reserved on Windows** (`a/b:c*?`, `CON`, `nul.txt`, trailing dots/spaces, 200-char names, emoji) → valid folder names, original name preserved in JSON. Test in Task 2.
3. **Two projects with the same name** (same `.3mf` imported twice) → two distinct folders, both listed. Test in Task 2.
4. **User text with HTML/filename-special characters** (`<b>&"Ana"</b>`, `a/b`) in company name, bill-to or plate names → escaped in the PDF HTML and sanitized in the invoice filename. Tests in Tasks 4 and 8.
5. **Logo file deleted or corrupted after being set** → invoice renders without a logo, no crash. Tests in Tasks 4 and 8.
