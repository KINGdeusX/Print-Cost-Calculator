# Print Cost Calculator v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the v0.1.1 single-window calculator as the `pcc` package — a pure-Python pricing core with a PySide6 desktop app, a CLI and a REST API — shipped as Windows and Linux binaries via GitHub Actions.

**Architecture:** `pcc.core` (stdlib + openpyxl) owns models, pricing, `.3mf` parsing, matching, persistence, serialization and xlsx export. `pcc.gui` (PySide6), `pcc.cli` (argparse) and `pcc.api` (FastAPI) are thin front-ends that only call core. The GUI holds a single `AppState` QObject that recalculates and debounce-saves on every change.

**Tech Stack:** Python ≥ 3.10, PySide6-Essentials, openpyxl, FastAPI + uvicorn + python-multipart (optional), pytest, pytest-qt, httpx, PyInstaller, appimagetool, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-17-pcc-v0.2-design.md` — read it alongside this plan; § references below point into it.

## Global Constraints

- Package name `print-cost-calculator`, import name `pcc`, `__version__ = "0.2.0"`.
- `pcc.core` and `pcc.cli` must not import PySide6, fastapi or pydantic (enforced by a test in Task 1).
- `openpyxl` is imported **inside** `pcc.core.export_xlsx` functions only, never at module import of anything the GUI loads at startup.
- Hidden plate fee, margin % and filament price/kg never appear in xlsx output or in the public API/JSON view.
- Failure allowance = (filament + electricity) × failure %; labor per plate; packaging once per job (§5 formulas verbatim).
- Final price rounding: `Decimal` ROUND_HALF_UP to `rounding_step`; step 0 → 2 decimals.
- Defaults: currency PHP `₱`, rate 12, labor 0, packaging 20, margin 50, failure 0, hidden fee 0, rounding step 5, theme `system`.
- Config dir: `PCC_CONFIG_DIR` → else `%APPDATA%\PrintCostCalculator` / `~/Library/Application Support/PrintCostCalculator` / `$XDG_CONFIG_HOME/print-cost-calculator` (default `~/.config/print-cost-calculator`).
- Exact user-facing copy: `"Not a valid .3mf file."`; `"No slice data. In Bambu Studio/OrcaSlicer use 'Export plate sliced file' or 'Export all sliced files'."`; `"Close the file in Excel, then retry"`; `"Drop a sliced .3mf or add a plate"`.
- JSON written with `ensure_ascii=False`, UTF-8.
- Work on branch `feature/v0.2`; commit after every task with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; `git push` after each task.
- Tests run with `QT_QPA_PLATFORM=offscreen` (set in `pyproject.toml` pytest config via `pytest-qt`'s `qt_api=pyside6` and an autouse env fixture in `tests/conftest.py`).

## Review Focus

1. **Empty or invalid v0.1 `pricing_config.json`** (the shipped `dist/pricing_config.json` is 0 bytes) → migration silently skips it and loads defaults. Test in Task 5.
2. **Unused AMS slots in a `.3mf`** (`used_g="0.00"`) → slot is dropped, not shown as a 0 g filament row; a plate whose slots are all 0 g is skipped. Test in Task 4.
3. **`settings.json` / `catalog.json` from another version** (unknown keys, missing keys) → unknown keys ignored, missing keys take defaults, no crash, no backup. Test in Task 3.
4. **Deleting the filament/printer the job uses, or the last one** → job falls back to the default; the last printer/filament cannot be deleted. Tests in Task 2 (catalog helpers) and Task 14 (dialog).
5. **Non-ASCII text** (customer `"Niño 🎉 Café"`, `₱`/`€` symbols) → round-trips intact through xlsx and JSON. Tests in Tasks 3 and 7.
